# leapster

A small, accurate Leapster emulator.

## Run

```
make # Needs SDL2

build/leapster BIOS CART [--eeprom FILE] [--save FILE] [--scale N]
```

Keys: arrows, Z = A, X = B, H = hint, Enter = home, P = pause.
